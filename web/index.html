Clé API Claude

Kotoba appelle Claude directement avec ta clé. Elle reste seulement sur ce téléphone.

  1. Ouvre platform.claude.com et connecte-toi (même compte que Claude).
  2. Billing : ajoute un peu de crédit. 5 $ suffisent pour des milliers de phrases.
  3. API Keys : « Create key ». Lie la clé à un workspace (par exemple Default), puis copie-la et colle-la ci-dessus.
  4. Clé déjà créée sans workspace ? Colle l’ID du workspace (colonne ID de la page Workspaces) dans le second champ.

C’est facturé à l’usage, à part de ton abonnement Claude.
